
Yazılım ve Güncellemelerin Kurulmasına Hoş Geldiniz.
Bu videoyu izledikten sonra şunları yapabileceksiniz:

Paketleri ve paket yöneticilerini tanımlamak,

Deb ve RPM tabanlı dağıtımlar için paketleri ayırt etmek,

Bir paket yöneticisi kullanarak güncellemeleri yüklemek,

Ve bir paket yöneticisi kullanarak yazılım yüklemek.

Linux işletim sistemleri için hem yazılım güncellemeleri hem de yazılım kurulum dosyaları paketler olarak bilinen dosyalar halinde dağıtılır.
Bu paketler, yeni yazılım yüklemek veya mevcut yazılımı güncellemek için gerekli bileşenleri içeren arşiv dosyalarıdır.

Paketlerin indirilmesi ve kurulumu için paket yöneticilerini kullanırsınız.
Farklı Linux dağıtımları farklı paket yöneticileri sağlar — bazıları GUI (grafik arayüz) tabanlıdır, bazıları ise komut satırı araçlarıdır.

Linux işletim sistemlerinde paket yöneticileri tarafından Deb ve RPM paketleri kullanılır.
Bunlar, farklı Linux işletim sistemleri için yazılım veya güncelleme içeren farklı dosya türleridir.

.deb dosyaları, Debian tabanlı dağıtımlar (Debian, Ubuntu, Mint gibi) için kullanılır. Deb, Debian’ın kısaltmasıdır.

.rpm dosyaları ise Red Hat tabanlı dağıtımlar (CentOS/RHEL, Fedora, openSUSE gibi) için kullanılır. RPM, Red Hat Package Manager’ın kısaltmasıdır.

Deb ve RPM formatları eşdeğerdir, yani dosyanın içeriği diğer Linux türlerinde de kullanılabilir.
Eğer kullanmak istediğiniz bir paket sadece diğer formatta mevcutsa, onu alien aracıyla dönüştürebilirsiniz.

RPM’den Deb’e dönüştürmek için alien komutunu paket ismiyle birlikte çalıştırın.

Deb’den RPM’e dönüştürmek için ise alien komutunda -r anahtarını kullanın.

Paket yöneticilerinin sağladığı avantajlar:

Paketler arasındaki bağımlılıkları otomatik olarak çözebilirler,

Güncellemeler mevcut olduğunda sizi bilgilendirebilirler,

GUI tabanlı paket yöneticileri, güvenlik ve yazılım güncellemelerini düzenli aralıklarla otomatik olarak kontrol edebilir,

Ve güncellemeleri otomatik olarak kurabilir veya sadece sizin seçtiklerinizi yüklemenize izin verirler.

GUI tabanlı Linux paket yöneticileri:

PackageKit ve Update Manager.

Update Manager, Deb tabanlı Linux sistemleri güncellemek için kullanılan GUI aracıdır.
Varsayılan olarak:

Günlük olarak yazılım güncellemelerini kontrol eder,

Güvenlik güncellemelerini otomatik indirip yükler,

Diğer tüm güncellemeleri ise haftalık olarak gösterir.

İstediğiniz zaman manuel olarak güncellemeleri kontrol edebilirsiniz.
Update Manager, yazılım güncellemeleri mevcut olduğunda sizi uyarır:

Yüklemek istediğiniz güncellemeleri seçin,

Install Updates (Güncellemeleri Yükle) butonuna tıklayın,

İstenirse kullanıcı şifrenizi girin ve OK’a tıklayın.
Update Manager, siz çalışmaya devam ederken güncellemeleri arka planda yükler.

Komut satırı aracı (Deb tabanlı):

apt, Deb tabanlı Linux sistemlerini güncellemek için kullanılan bir komut satırı aracıdır.

sudo apt update komutu, dağıtımınız için mevcut paketleri bulmak amacıyla kullanılır.
Bu komutun çıktısı:

Mevcut paketleri listeler,

Bir bağımlılık ağacı oluşturur,

Kaç paketin yükseltilebileceğini gösterir.

Tüm paketleri yükseltmek için: sudo apt upgrade

Belirli bir paketi yüklemek için: sudo apt install package_name

GUI tabanlı Linux paket yöneticisi (RPM tabanlı):

PackageKit, RPM tabanlı Linux sistemlerini güncellemek için kullanılan GUI aracıdır.

Güncellemeler mevcut olduğunda bildirim alanında yıldız patlaması simgesi görüntüler.

Belirli aralıklarla otomatik güncellemeleri kontrol eder.

Manuel olarak da kontrol edebilirsiniz.

Simgeye tıklamak, Software Update (Yazılım Güncelleme) penceresini açar. Burada mevcut güncellemeler listelenir:

Yüklemek istediklerinizi seçin,

Install Updates (Güncellemeleri Yükle) butonuna tıklayın,

İstenirse şifrenizi girin ve OK’a tıklayın.
PackageKit, siz çalışmaya devam ederken güncellemeleri arka planda yükler.

Komut satırı aracı (RPM tabanlı):

yum, RPM tabanlı sistemleri güncellemek için kullanılan bir komut satırı aracıdır.
Yum, Yellowdog Updater Modified’in kısaltmasıdır.

Tüm paketleri güncellemek için: sudo yum update

Parolanızı girdikten sonra, yum tüm mevcut güncellemeleri getirir,

Bir özet gösterir ve sizden onay ister,

Onay verirseniz, güncellemeleri indirip yükler,

İşlem bittiğinde Complete! mesajını gösterir.

Yazılım yüklemek için de kullanılabilir:

Deb tabanlıda → sudo apt install paket_adi

RPM tabanlıda → sudo yum install paket_adi

Ek olarak:

Birçok yazılım uygulaması da kendi paket yöneticisini kullanır.
Örneğin, Python ortamlarını yönetmek için popüler pip veya conda paketleri vardır.

Örneğin:
Python ortamınız ve pip paketiniz zaten yüklüyse, veri işleme için kullanılan popüler pandas kütüphanesini şu şekilde yükleyebilirsiniz:

pip install pandas

Bu komut pip’e şunu söyler:

En son pandas paketini bul,

İndir,

Gerekli bağımlılıkları kontrol edip güncelle,

Ve pandas’ı yükle.

Kurulum tamamlandığında, paket yöneticisi yeni yazılım sürüm numarasını görüntüler.

Bu videoda öğrendikleriniz:

.deb ve .rpm, Linux işletim sistemlerinde kullanılan farklı paket türleridir,

Deb ve RPM formatları birbirine dönüştürülebilir,

Update Manager ve PackageKit, sırasıyla Deb ve RPM tabanlı dağıtımlarda kullanılan popüler GUI tabanlı paket yöneticileridir,

apt ve yum, sırasıyla Deb ve RPM tabanlı dağıtımlarda kullanılan popüler komut satırı paket yöneticileridir.
